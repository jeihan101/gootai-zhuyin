02 ／ 使用方法

先確認模式，再套用。

  1. 確認素材拍攝模式為 D-Log 或 D-Log 2，選擇對應檔案。D-Log M 不適用。
  2. 在前段調整曝光與白平衡，下一節點套用對應直接版 LUT，先以 100% 使用。
  3. 直接版已含 Log 還原，請勿再疊官方還原 LUT 或其他 Log → Rec.709 轉換；確認軟體沒有先做自動輸入轉換。
  4. 若想調整風格強弱，改用「匹配的 DJI 官方還原 LUT → Rec.709 Look Only」順序，只調整 Look Only 的混合量。
  5. 以 SDR Rec.709 監看與輸出。HDR、ACES 或廣色域流程請先閱讀完整說明，確認轉換邊界。

固定 LUT 無法恢復已裁切的高光，也不能重現顆粒、光暈或 Alexa 感光元件。建議先用人物、天空及高反差場景試用，再微調白平衡與曝光。
