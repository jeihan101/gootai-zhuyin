03 ／ 安裝說明

幾個步驟，
回到打字這件事。

macOS

  1. 下載並開啟 .pkg，依安裝程式完成安裝。
  2. 開啟「系統設定 → 鍵盤 → 文字輸入 → 編輯」，新增「繁體中文 → 鼓太注音」。
  3. 從輸入法選單選擇「鼓太注音」，即可開始使用。若清單尚未出現，存好工作後登出再登入一次。

Windows

  1. 下載並開啟 .exe，依安裝程式完成安裝。
  2. 開啟「設定 → 時間與語言」，在繁體中文的語言選項中加入「鼓太注音」。
  3. 使用 Win + Space 切換到鼓太注音。升級後若仍載入舊版，存好工作後登出再登入。
升級會保留自己的詞庫嗎？

1.4 延用原有鼓太注音的資料位置。升級前仍建議從詞彙編輯程式匯出備份；安裝檔不包含任何人的私人詞彙或學習紀錄。

候選字配色在哪裡調整？

開啟鼓太注音偏好設定，在「一般 → 候選字配色」選擇黑色、灰色或白色。上方的配色預覽只是網頁示意，不會更動你電腦的設定。

兩個版本的支援與測試範圍

macOS 版支援 Apple 晶片與 Intel，已在 macOS 27.0.1 使用。Windows 版目前為預覽版，支援 x64 Windows 10 以上，包含 x86 應用程式；雲端測試不能取代 Windows 電腦上的完整打字驗證。兩版目前都未整合善解模型。
